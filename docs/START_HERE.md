# 从这里开始

1. 在 GitHub 新建一个仓库，例如 `codex-starter`。尚未决定公开内容时可以选 Private。
2. 将起步包解压后的内容放进仓库根目录，注意保留 AGENTS.md 和隐藏配置文件。
3. 在支持仓库开发的 Codex 使用方式中选择这个仓库；若仓库不出现，检查 GitHub 应用对该仓库的访问权限。
4. 先发送 README 的第一条任务，观察它读取文件、修改程序、运行测试的过程。
5. 检查修改内容，确认功能后再合并到主分支。

如果 GitHub 插件能访问仓库，也可以直接把仓库链接发给当前对话，让助手提交起步文件。

## 每次任务提供四件事

- 要解决的问题：例如“任务多时找不到某一项”。
- 希望看到的行为：例如“输入关键词显示匹配标题的任务”。
- 限制：例如“不接付费服务，保留现有命令”。
- 验收方式：例如“中文关键词可用；没有匹配时给提示”。

## 后续练习

按需要逐个增加：关键词搜索、撤销完成、截止日期、CSV 导出、网页界面。不要一次要求全部实现。每次保留一个可验证、可回退的改动。
